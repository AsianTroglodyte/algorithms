** RB-tree properties

it has other properties as well:
 1. A node is either red or black.
 2. the root is black
 3. leaves (NIL) are black.
 4. If a node is red, then its children are black.

    NOTE: invariant 5 is the main balancing invariant
 5. All paths from any node to its NIL descendants contain the same number of
    black nodes. reiterate. This invariant hold for ALL nodes. in RB tree
